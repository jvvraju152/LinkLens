              Installation Instructions

              1. Click the Download Extension (.zip) button above and extract (unzip) the archive on your computer.
              2. Navigate to chrome://extensions (or edge://extensions in Edge).
              3. Enable Developer mode using the toggle switch in the top-right corner.
              4. Click Load unpacked and select the extracted extension folder.
              5. Ensure the extension server address is set to: http://127.0.0.1:5000
              6. Right-click any link on any web page and select "Check link with LinkLens".
